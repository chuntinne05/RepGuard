**Date:** 02/10/2026. This is a train-only capability probe, not a benchmark submission or DART/HistRepEval result. V4–v6 used a custom ReAct harness; v7 asks whether AppWorld's own version-matched legacy Recoma ReAct scaffold makes Qwen3 32B more capable on fresh tasks.

- **Tasks:** `afc0fce_2`, `27e1026_2`, `6ea6792_2`, positions 10–12 of the previously frozen SHA-256 one-per-generator train list. No dev or test task is opened. These task IDs were selected before looking at instructions or gold.
- **Model:** same Qwen3 32B Q4_K_M parent digest `030ee887880fc378860c2dd35101da424377520441ae4bfe7be6deff8ade7840` as v4–v6. Ollama alias `qwen3:32b-ctx8192` sets `num_ctx=8192`; OpenAI-compatible `/v1/chat/completions` receives `reasoning_effort=none`, temperature 0, top_p 1, seed 123, max_tokens 1024. The deployment is `ollama-server-repguard-l4/OllamaServer`.
- **Agent:** version-matched official `AppworldReactController`, `AppworldPromptedLMModel`, `AppworldEnvironmentModel`, Recoma best-first search, and `experiments/prompts/react.txt`. The adapted budget is max 40 LLM and 40 environment calls per task; prompt and controller history are each bounded at 20,000 characters. The official prompt/config was designed for GPT-4o with 100 calls and 400 output tokens, so this is **an adapted legacy-agent reference**, not reproduction of the paper's original GPT-4o result. The v4–v6 tasks are different; success counts are not paired estimates.
- **Gold isolation:** `AppWorld.init_defaults.load_ground_truth=False`. The official prompt model computes a `relevant_apis` template field from gold, even though the ReAct template does **not** interpolate that field. The adapter replaces that field with `[]` and asserts the world has no ground truth. The official answerer calls `world.evaluate()` in the agent process; the adapter instead saves the trajectory and closes the world. AppWorld's official state-check runs later in a fresh process. Only these two gold-boundary hooks and Modal transport are adapted; no task-specific API hints are inserted.
- **Outputs:** Git-ignored `results/appworld_external_v1/train_pilot_v7_legacy_react/`, including per-task trajectories, model-call counts, manifest and later fresh-process state-checks. Interrupted partial tasks are excluded and rerun cleanly. Do not expose protected task text in Git.

The protocol implementation is `run_appworld_legacy_react_v7.py`. Run at most one task first as a transport/agent smoke gate, inspect its trace and state-check, then run the other two if the adapter works. A technical failure is not scored as a task failure. Report task success, passed/total checks, model calls, environment calls and token cost; do not call this an official AppWorld leaderboard score.

## Decision rule

If the legacy scaffold solves no task, conclude only that **this model/agent/budget combination** has not established a viable AppWorld agent pool; stop building AppWorld HistRepEval around it and seek a stronger compatible model or easier complementary agent pool before method tests. If it solves tasks, run a larger prospectively selected train capability sample and then paired DART/ERCT comparisons with the same agent/model budget before opening dev. Neither outcome guarantees a publication venue or a method gain.
